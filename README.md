
  # Photography portfolio design

  This is a code bundle for Photography portfolio design. The original project is available at https://www.figma.com/design/QmoT95TYxR2xObZKOfCt3r/Photography-portfolio-design.

  ## Running the code

This project has been converted to run without React, using vanilla JavaScript, HTML, and CSS.

Run `npm i` to install the dependencies.

Run `npm run dev` to start the development server.

The site now uses:
- Vanilla JavaScript for interactivity
- Tailwind CSS for styling
- No React dependencies
